# Training stack constraints.
#
# These pins are CUDA-coupled and don't resolve cleanly across darwin/arm64
# and linux/x86_64 in a single uv lock, so we install them out-of-band per
# platform:
#
#   M1 smoke (no CUDA, no bitsandbytes; LoRA in BF16):
#     uv pip install -c constraints/train.txt \
#         trl peft transformers accelerate datasets wandb
#
#   Linux + CUDA (paid GPU; full QLoRA stack):
#     uv pip install -c constraints/train.txt \
#         unsloth trl peft transformers accelerate datasets bitsandbytes wandb
#
# Ranges come from the compatibility matrix; refresh after the first
# successful install on each platform.
